============================== General Commands ============================
---> ls :-
	* This command is used to show files and directories in a location.
	* Basic usage and different formats of usage of 'ls' command is given below:
		--> ls :-
			* This command is used to show files and directories in current working directory.
			
		--> ls / :-
			* This command is used to show files and directories in root(/) directory.
			* No matter which directory we are in.
			
		--> ls /<directory_name> :-
			* This command is used to show files and directories in 'directory_name' directory.
			* No matter which directory we are in.
			* If 'directory_name' not found in the root(/) directory, it will give error like 'ls: cannot access '/directory_name': No such file or directory'.
		
		--> ls <directory_name> :-
			* This command is used to show files and directories in 'directory_name' directory.
			* The 'directory_name' directory should be in the current working directory.
			* * If 'directory_name' not found in the current working directory, it will give error like 'ls: cannot access 'directory_name': No such file or directory'
		
		--> ls -l :-
			* This command is used to show files and directories with additional information like permissions, owner, file size, date and file name in current working directory.
		
		--> ls -a :-
			* This command is used to show all files and directories including hidden files and directories.
		
		-- ls -al or ls -la :-
			* This command is used to show all files and dirctories including hidden files and directories with additional information.
		
		--> ls -lh or ls -hl :-
			* This command is used to show files and directories with additional information and the file or directory size is in human reable format.
			* The 'ls -h' command will not show any additional informantion.
		
		--> ls -t :-
			* This command is used to show files and directories sort by time in descending order (means latest files first).
		 
		--> ls -lt or ls -tl :-
			* This command is used to show files and directories with additional informantion and sort by time in descending order.
		
		--> ls -r :-
			* This command is used to show files and directories in reverse order.
			
		--> ls -tr or ls -rt :-
			* This command is used to show files and directories sort by time in ascending order.
			
		--> ls -R :-
			* This command is used to show files and dirctories recursively.
		
		--> ls -F :-
			* This command is used to show files and directories with type.
			* '/' denotes directory and '*' denotes executable file.
			
=================== File Operation Commands	==================	
--> basename :-
	* This command is used to extract the file name from a full path.
	* It is useful in scripts to avoid manual string handlings
	* To work with 'basename' files or directories does not need to exist.
	* Basic usage and different formats of usage of 'basename' command is given below:
	--> basename /<directory_name>/<file_name> or basename <directory_name>/<file_name> :-
		* This command remove the directory related part and return the 'file_name'.
	
	--> basename /<directory_name_1>/<directory_name_2> or basename <directory_name_1>/<directory_name_2> :-
		* This command remove the directory related part and return the 'directory_name_2'
		
	--> basename /<directory_name_1>/<directory_name_2>/ or basename <directory_name_1>/<directory_name_2>/ :-
		* This command remove the directory related part and return the 'directory_name_2'
	
	--> basename /<directory_name>/<file_name.extension> or basename <directory_name>/<file_name.extension> :-
		* This command remove the directory related part and .extension and return the 'file_name'.

--> dirname :-
	* This command is used to extract the directory path from a full file or directory path.
	* It will removes the last part(file or directory name) and returns the remaining path.
	* To work with 'dirname' files or directories does not need to exist.
	* Basic usage and different formats of usage of 'dirname' command is given below:
	--> dirname /<directory_name_1>/<directory_name_2>/<file_name> or dirname /<directory_name_1>/<directory_name_2>/<file_name> :-
		* This command will remove 'file_name' from the path and return '/<directory_name_1>/<directory_name_2>' or '<directory_name_1>/<directory_name_2>'.
	
	--> dirname /<directory_name_1>/<directory_name_2>/<directory_name_3> or dirname /<directory_name_1>/<directory_name_2>/<directory_name_3> :-
		* This command will remove 'directory_name_3' from the path and return '/<directory_name_1>/<directory_name_2>' or '<directory_name_1>/<directory_name_2>'.
	
	--> dirname /<directory_name_1>/<directory_name_2>/ or dirname /<directory_name_1>/<directory_name_2>/ :-
		* This command will remove 'directory_name_2/' from the path and return '/<directory_name_1>' or '<directory_name_1>'.	
	
	--> dirname / or dirname /<directory_name> :-
		* This command will return '/', means it will return root(/).
	
	--> dirname <directory_name> or dirname ,file_name> :-
		* This command will return '.'
